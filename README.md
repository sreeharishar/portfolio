# Harish Ambalam Rajasimman Portfolio

A personal portfolio website for Harish Ambalam Rajasimman, a Business Intelligence Specialist focused on Tableau administration, analytics engineering, governance automation, and enterprise monitoring.

## Overview

This repository contains a modern one-page portfolio built with static HTML, CSS, and JavaScript. It showcases:

- professional background and experience
- technical expertise
- selected project work
- education and publications
- contact details and resume link

## Live Site

Open `index.html` in a browser, or serve the project locally with a simple static server.

## Local Development

Because this is a static website, there is no build step required.

Option 1: open `index.html` directly in a browser.

Option 2: run a small local web server:

```bash
cd portfolio
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

You can personalize the site by updating the following:

- name and title in `index.html`
- contact email and LinkedIn/GitHub links
- resume file path in `assets/resume/`
- profile image and branding assets in `assets/img/`
- section content for experience, projects, and education

## Deployment

This project can be deployed on any static hosting service, including:

- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
